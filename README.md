## О проекте

Этот проект представляет собой утилиту _Folder Structure Viewer_ для визуализации структуры папок и файлов в указанной директории.

## Основные возможности

- **Интеллектуальный обход директорий** с настраиваемыми исключениями:
  - Скрытые системные папки (`.git`, `.idea`, `.vscode`, `__pycache__`, `node_modules`)
  - Отдельные файлы по имени
  - Файлы по расширению (`*.dll`, `*.qm`, `*.wt`, `*.pod`, `*.pm`, `*.pl`, `*.al`, `*.xml`)
- **Множественные режимы работы**:
  - Интерактивный режим с пошаговым вводом
  - Командная строка с аргументами
  - Тихий режим (`--quiet`) для минимального вывода
  - Режим только с конфигурацией (`--config-only`)
- **Детальная статистика**: информация о количестве папок, файлов и их размерах
- **Наглядное древовидное отображение** структуры с эмодзи-иконками
- **Гибкая конфигурация** через файл `exceptions.txt` и аргументы командной строки
- **Система исключений**: возможность игнорировать нежелательные файлы и папки

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/SawGoD/Folder-Structure-Viewer.git
   cd Folder-Structure-Viewer
   ```

2. Запустите скрипт:
   ```bash
   python fsv.py
   ```

## Использование

### Быстрый старт

```bash
# Анализ текущей директории (самый простой способ)
python fsv.py

# Анализ текущей директории без указания пути
python fsv.py .

# Анализ конкретной папки
python fsv.py /path/to/folder

# Анализ в тихом режиме (только дерево файлов)
python fsv.py . --quiet

# Анализ с дополнительными исключениями
python fsv.py /path -d node_modules .git -e .pyc .log -f config.ini
```

### Аргументы командной строки

| Аргумент | Краткая форма | Описание |
|----------|---------------|----------|
| `path` | - | Путь к папке для анализа (по умолчанию: текущая директория) |
| `--exclude-dirs` | `-d` | Папки для исключения |
| `--exclude-extensions` | `-e` | Расширения файлов для исключения |
| `--exclude-files` | `-f` | Конкретные файлы для исключения |
| `--quiet` | `-q` | Тихий режим - только дерево файлов без статистики |
| `--config-only` | `-c` | Использовать только конфигурацию из файла `exceptions.txt` |
| `--no-config` | - | Не загружать исключения из файла `exceptions.txt` |
| `--interactive` | `-i` | Принудительный интерактивный режим |

### Примеры использования

#### 1. Анализ текущей директории
```bash
# Простейший способ - анализ текущей папки
python fsv.py

# То же самое, но явно указав текущую папку
python fsv.py .

# Анализ текущей папки в тихом режиме
python fsv.py . -q
```

#### 2. Анализ конкретной папки
```bash
# Анализ конкретной папки
python fsv.py /home/user/projects

# Анализ с дополнительными исключениями
python fsv.py /home/user/projects -d build dist -e .pyc .pyo
```

#### 3. Тихий режим
```bash
# Только структура файлов без дополнительной информации
python fsv.py /path/to/project --quiet

# Краткая форма
python fsv.py /path/to/project -q
```

#### 4. Работа с конфигурацией
```bash
# Использовать только настройки из exceptions.txt
python fsv.py . --config-only

# Игнорировать файл exceptions.txt
python fsv.py . --no-config

# Добавить исключения к существующим из файла
python fsv.py . -d temp cache -e .tmp .bak
```

#### 5. Интерактивный режим
```bash
# Принудительный интерактивный режим
python fsv.py --interactive

# Или просто запустить без аргументов
python fsv.py
```

### Конфигурация через файл exceptions.txt

Программа автоматически загружает исключения из файла `exceptions.txt`, расположенного в той же папке, что и скрипт. Формат файла:

```
# Папки для исключения
node_modules
.git
.idea
.vscode
__pycache__

# Расширения файлов (с *)
*.dll
*.qm
*.wt
*.pod
*.pm
*.pl
*.al
*.xml

# Конкретные файлы
config.json
.env
```

**Правила формата:**
- Строки, начинающиеся с `*.` — расширения файлов
- Строки, начинающиеся с `.` и без точек далее — системные папки
- Строки с точкой внутри — конкретные файлы
- Остальные строки — обычные папки
- Пустые строки игнорируются

## Продвинутое использование

### Сценарии использования

1. **Анализ проекта для документации:**
   ```bash
   python fsv.py . -d node_modules .git build dist -e .pyc .pyo .class
   ```

2. **Быстрый обзор структуры в CI/CD:**
   ```bash
   python fsv.py . --quiet --config-only
   ```

3. **Анализ с нуля (без предустановленных исключений):**
   ```bash
   python fsv.py . --no-config
   ```

4. **Интерактивная настройка для нового проекта:**
   ```bash
   python fsv.py --interactive
   ```

### Статистика

Программа предоставляет детальную статистику:
- **Общее количество папок** (включая скрытые и пустые)
- **Общее количество файлов** (включая скрытые)
- **Общий размер** всех видимых файлов
- **Соотношение скрытых элементов** к общему количеству

### Размеры файлов

Размеры автоматически форматируются в удобочитаемый вид:
- Байты (Б)
- Килобайты (КБ)
- Мегабайты (МБ)
- Гигабайты (ГБ)
